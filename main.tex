\chapter*{Abstract}
This thesis investigates dimensionality reduction strategies for multivariate time series (MTS) across varied domain topologies, including motion capture sensor arrays and high-density electroencephalography (EEG). By framing sensor pruning through both unsupervised principal component representation learning and supervised temporal statistical filtering, this work evaluates information retention using non-parametric Monte Carlo permutation testing. The findings demonstrate that PCA-based loading selection and subspace divergence successfully isolate task-discriminative cortical regions while pruning redundant hardware channels.
